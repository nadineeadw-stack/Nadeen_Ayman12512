⚖️ Class Imbalance Analysis

The Problem

Positive class (Disease) is severely underrepresented:

  • No Disease: 91.06%
  • Disease: 8.94%

A naive model predicting "No Disease" for all cases achieves 91% accuracy while failing clinically.

Mitigation Strategy

  • class_weight='balanced' in Logistic Regression, Decision Tree
  • scale_pos_weight in XGBoost
  • Stratified Train/Test split to preserve class distribution
  • Evaluation focused on Recall and ROC-AUC rather than Accuracy

🤖 Model Selection Strategy

Six candidate models evaluated. Selection criteria prioritized Recall (Sensitivity) for the positive class to minimize false negatives in a clinical setting.

✅ Selected Models

  • Logistic Regression — Baseline linear model with probabilistic output
  • XGBoost — Gradient-boosted trees with regularization
  • Decision Tree — Interpretable rule-based classifier
  • Gradient Boosting — Sequential error-correcting ensemble

❌ Rejected Models

  • Random Forest — Recall: 0.097 (misses 90% of cases)
  • K-Nearest Neighbors — Recall: 0.16 (misses 84% of cases)

Rejected due to clinically unacceptable false negative rates. Missing a true positive (sick patient) is far costlier than a false alarm.

Clinical Cost Analysis

  • False Negative Cost: Delayed treatment, disease progression, potential fatality
  • False Positive Cost: Additional testing, patient anxiety, resource allocation

In screening contexts, optimizing Recall (Sensitivity) is paramount. We accept lower Precision to ensure minimal missed cases.

📈 Ensemble Results Analysis

✅ Strengths

  • Stability: Reduced variance compared to individual models
  • ROC-AUC 0.84: Strong discriminative ability between classes
  • Balanced Trade-off: Better generalization across threshold ranges
  • Robustness: Less sensitive to individual model failures

⚠️ Limitations

  • Recall remains moderate (33%): Still misses ~67% of true cases
  • Class imbalance persists: Fundamental dataset limitation
  • Precision (Disease): ~34% — high false positive rate
  • Not yet suitable for standalone clinical diagnosis without physician oversight

🔮 Future Work & Recommendations

🧪 Data-Level Improvements

  • SMOTE / ADASYN: Synthetic minority oversampling to address class imbalance
  • Threshold Optimization: Tune decision threshold to maximize sensitivity
  • Feature Selection: Recursive Feature Elimination (RFE) to reduce dimensionality

🤖 Model-Level Improvements

  • Deep Learning: Experiment with Neural Networks and TabNet architectures
  • Cost-Sensitive Learning: Assign higher misclassification cost to false negatives
  • Stacking Ensemble: Meta-learner (e.g., Logistic Regression) on top of base models

🏥 Clinical Integration

  • Electronic Health Record (EHR) integration for automated screening
  • Explainable AI (XAI): SHAP values for clinician-facing model interpretability
  • A/B Testing: Validate model impact on patient outcomes in pilot programs
